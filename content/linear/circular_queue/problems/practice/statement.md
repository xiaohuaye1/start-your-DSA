# 循环队列实战：空槽法与下标回绕

## 训练目标

将顺序队列改为环形结构，真正用取模回收空间，不通过搬移数组来模拟。使用“保留一个空槽”的办法区分空与满，并输出下标验证回绕。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调，不要直接抄整份参考答案。

## 输入

第一行 capacity q，随后 q 行操作。2≤capacity≤7，1≤q≤16，元素绝对值≤100。capacity 是数组槽数，最多放 capacity-1 个元素，初始 front=rear=0。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 value` | 入队，输出 `OK` 或 `FULL` |
| `2` | 出队并输出值；空队列输出 `EMPTY` |
| `3` | 查看队头，不出队；空队列输出 `EMPTY` |
| `4` | 输出 size |
| `5` | 从队头起输出逻辑队列，空队列输出 `EMPTY` |
| `6` | 清空并将 front、rear 都置 0，输出 `OK` |
| `7` | 输出 `front rear` |

不打印菜单和额外提示文字。

## 建议实现

- 用 Queue 结构体维护 data、front、rear、capacity，实现 `queueinit / isempty / isfull / size / q_push / q_pop / front_value / clear`。
- 空：front==rear；满：(rear+1)%capacity==front。
- 入队与出队后对应下标取模；size 计算差值并修正回绕。
- 遍历按逻辑顺序进行，不能简单遍历 data[front..rear)；不要搬移数组。

## 分步提示

逻辑容量和物理槽数相差 1。遍历下一个元素的位置是 (index+1)%capacity。满队列继续入队不得覆盖队头，空队列出队不得改变 front。
