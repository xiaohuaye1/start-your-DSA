# 洛谷 P1739 · 表达式括号匹配

来源：[洛谷 P1739「表达式括号匹配」](https://www.luogu.com.cn/problem/P1739)。以下为本项目的题意转述，样例和参考代码自行编写。

输入一行表达式，以 @ 结束。检查圆括号是否正确匹配，输出 YES 或 NO。忽略数字、字母和运算符，@ 不参与匹配。

原题表达式长度小于 255、左括号少于 20。本地只用短表达式，包含嵌套正确、缺少右括号、右括号提前出现三种普通情况。

## 本地样例

输入：
```text
(a+b)*(c-d)@
```

输出：
```text
YES
```
