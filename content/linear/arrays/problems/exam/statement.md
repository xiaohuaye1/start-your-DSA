# 洛谷 P1428 · 小鱼比可爱

## 题意与格式
第一行 n，第二行 n 个非负整数 a[i]。对每个位置 i，统计左侧 j<i 中满足 a[j]<a[i] 的元素数量，依次输出这 n 个计数。

相等不算；只能看左侧，不能统计右侧。

原题范围：1≤n≤100，0≤a[i]≤10。本地仅用 4～6 个普通数。

## 本地样例

输入：
```text
5
4 3 5 2 5
```

输出：
```text
0 0 2 0 3
```
