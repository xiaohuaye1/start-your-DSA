# 顺序表实战：插删查改与动态扩容

## 训练目标

从“修改一个数组元素”升级为一个完整的顺序表。用带 length、capacity 和 int *data 的结构体管理数据，自己实现插入、删除、查找、反转和释放。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调命令，不要直接抄整份参考答案。

## 输入

第一行 n q，第二行 n 个整数（n=0 时可省略），之后 q 行操作。0≤n≤8，1≤q≤16，元素绝对值≤100。位置从 1 开始；最多保留 24 个元素。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 position value` | 在位置 position 插入；合法范围 1～length+1，成功输出 `OK`，否则 `INVALID` |
| `2 position` | 删除并输出被删值；合法范围 1～length，否则 `INVALID` |
| `3 value` | 输出第一次出现的位置；找不到输出 0 |
| `4` | 原地反转，不输出 |
| `5` | 按当前顺序输出；空表输出 `EMPTY` |
| `6` | 输出 length |

所有查询或状态输出各占一行，不打印菜单和额外提示文字。

## 建议实现

- 实现 `initList / append / insert_at / delete_at / search / reverse / release`。
- 建议初始容量为 4，不足时用 realloc 扩容，区分“容量”与“当前长度”。
- 插入从后往前搬，删除从前往后搬；把删掉的元素通过 `int *e` 返回。
- 允许尾插 position=length+1；非法操作不得修改原表。

## 分步提示

位置是从 1 开始的，下标是从 0 开始的。删除的最后一次搬移应读取原来最后一个有效元素，不要读取 data[length]。realloc 先交给临时指针，成功后再替换 data。

## 样例

输入：
```text
3 9
2 4 6
1 1 9
1 5 8
2 3
3 8
4
5
6
1 0 7
5
```

输出：
```text
OK
OK
4
4
8 6 2 9
4
INVALID
8 6 2 9
```
