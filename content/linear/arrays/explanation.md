# 数组

## 下标与连续存储
C 数组元素类型一致，使用从 0 开始的下标。长度为 n 时，合法下标是 0～n-1。数组访问不会自动做越界检查。

## 访问与修改
动画先选择中间下标，读取该元素，再把它加 1，最后从左到右遍历。观察“下标定位一次”与“完整遍历 n 次”的区别。

```c
int value = a[index];
a[index] = value + 1;
for (int i = 0; i < n; ++i) printf("%d ", a[i]);
```

## 地址示意
假设起始地址为 1000、每个 int 占 4 字节，则第 i 项地址是 1000+i×4。这里只是示意；实际类型大小要用 sizeof(int)，真实地址由运行环境决定。

## 复杂度
按下标读取或赋值通常为 O(1)；完整遍历 O(n)。访问第 i 项不需要先访问前面所有元素。

## 真题练习
P1428 对每个位置 i 检查它左边的 j<i，统计严格小于 a[i] 的数量。相等不计数。普通双层循环对 n≤100 足够，本地只跑 4～6 个元素。
