# 双向链表实战：双向一致与原地反转

## 训练目标

用一个带头节点的双向循环链表同时维护 prev 和 next。只输出正向序列不足以发现漏接 prev，这次要正反遍历、头尾插删并反转整个链表。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调命令，不要直接抄整份参考答案。

## 输入

第一行 n q，第二行 n 个整数（n=0 可省略），随后 q 行操作。0≤n≤8，1≤q≤16，元素绝对值≤100。位置从 1 开始，头节点不计入长度。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 position value` | 插入；1～length+1 合法，输出 `OK`，否则 `INVALID` |
| `2 position` | 删除并输出值；位置不合法输出 `INVALID` |
| `3` | 正向输出序列，空表输出 `EMPTY` |
| `4` | 反向输出序列，空表输出 `EMPTY` |
| `5` | 原地反转整个表，不输出 |
| `6` | 输出 length |

所有查询或状态输出各占一行，不打印菜单和额外提示文字。

## 建议实现

- 定义 Node（data、prev、next）和 DoublyList（head、length）。空表的 head->next 与 head->prev 都指向 head。
- 实现 `initList / insert_at / delete_at / print_forward / print_backward / reverse / release`。
- 插入或删除时维护两边的链接；反转时交换每个节点以及头节点的 prev、next。
- 用动态节点完成，不用数组伪装双向链表；释放全部节点。

## 分步提示

在 node 前插入时，一共要接好前驱、node 和新节点之间的 4 条链接。反转之后沿哪个方向继续遍历？可以保存原 next，或沿交换后的 prev 前进。

## 样例

输入：
```text
3 8
1 2 3
1 2 9
3
4
2 4
5
3
4
6
```

输出：
```text
OK
1 9 2 3
3 2 9 1
3
2 9 1
1 9 2
3
```

## 写完后自查

任何节点是否满足 p->next->prev==p 和 p->prev->next==p？删掉唯一节点后两个头指针是否正确？反向输出是不是正向输出的逆序？
