# 双向链表删除节点

第一行 `n position`，第二行 n 个整数。2≤n≤100，position 从 1 开始且 1≤position≤n。

补全 `remove_at`，同时更新 prev 与 next，返回新 head。第一行正向输出剩余序列，第二行反向输出。不要只修改一个方向。

## 本地样例

输入：
```text
5 3
3 1 4 2 5
```

输出：
```text
3 1 2 5
5 2 1 3
```
