# 单链表实战：完整操作与快慢指针

## 训练目标

自己用 malloc 建立带头节点的单链表，不再只连接一个节点。把初始化、头尾插、指定位置插删、查找、反转、快慢指针与释放全部写出来。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调命令，不要直接抄整份参考答案。

## 输入

第一行 n q，第二行 n 个整数（n=0 时可省略），之后 q 行操作。0≤n≤8，1≤q≤16，元素绝对值≤100。位置从 1 开始，头节点不计入长度。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 position value` | 插入到 position，合法范围 1～length+1；输出 `OK` 或 `INVALID` |
| `2 position` | 删除并输出值；非法位置输出 `INVALID` |
| `3 value` | 第一次出现的位置，找不到输出 0 |
| `4` | 原地反转，不输出；保留原头节点 |
| `5` | 输出链表，空表输出 `EMPTY` |
| `6` | 输出实际节点数 |
| `7 k` | 用快慢指针找倒数第 k 个；k 不在 1～length 时输出 `INVALID` |
| `8` | 输出中间节点的值；偶数长度取靠后的一个，空表输出 `EMPTY` |
| `9 value` | 头插，输出 `OK` |
| `10 value` | 尾插，输出 `OK` |

所有查询或状态输出各占一行，不打印菜单和额外提示文字。

## 建议实现

- 定义 `typedef struct Node { int data; struct Node *next; } Node`，实现 initList、inserthead、inserttail、insert_at、delete_at、search、reverse、countdown、middle、release。
- 删除时先保存待删节点，再断开连接，最后 free 待删节点。
- 反转用三个指针完成，不另外复制数组或整条链表。
- 倒数第 k 个不能先转数组；主任务要求练习快慢指针。
- 结束时释放所有数据节点和头节点。

## 分步提示

反转的循环开始时不要直接读取第一个节点的 next，因为空链表的第一个节点是 NULL。快指针先走 k 步，每一步先检查指针。C++ 中 delete 是关键字，函数名请用 delete_at 等。

