# 链表

## 节点与连接
单链表节点含 value 和 next。head 指向首节点，尾节点的 next 为 NULL。数据的逻辑顺序由 next 决定，不要求物理地址连续。

## 动画
先沿 next 遍历，再在中间节点后插入一个值为 9 的新节点；最后移除这个新节点。#1 等是稳定节点编号，不是真实地址。上方保留初始数据，下方展示实际链与各节点的 next，包括尚未接入的节点。

## 插入顺序
先做 node->next = previous->next，再做 previous->next = node。反过来会丢失原后继。删除后继时先保存被删节点，再把 previous->next 改为 victim->next。

## 时间与内存
已知前驱时插入/删除 O(1)，查找前驱通常 O(n)。练习用稳定的节点池，若使用 malloc 分配节点，删除时还需要 free，不能继续访问被释放节点。

## 实操与真题
实操补全指针插入，插入位置从 1 开始。B3631 用数组下标模拟 next，节点值就是编号，0 表示尾后。操作 3 删除 x 的后继，不是删除 x。
