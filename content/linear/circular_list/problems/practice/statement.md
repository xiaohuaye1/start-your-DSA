# 循环链表实战：自环、旋转与插删

## 训练目标

自己建立带头节点的循环单链表，空表时 head->next=head。写插删之后再旋转，验证每次修改后整条链仍然能回到头节点。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调命令，不要直接抄整份参考答案。

## 输入

第一行 n q，第二行 n 个整数（n=0 可省略），随后 q 行操作。0≤n≤8，1≤q≤16，元素绝对值≤100；旋转步数 0≤k≤20。位置从 1 开始，头节点不计入长度。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 position value` | 在位置插入；1～length+1 合法，输出 `OK`，否则 `INVALID` |
| `2 position` | 删除并输出值；1～length 合法，否则 `INVALID` |
| `3 k` | 向左旋转 k 个数据节点，不输出；空表不变 |
| `4` | 从头节点后开始输出一圈，空表输出 `EMPTY` |
| `5` | 输出 length |

所有查询或状态输出各占一行，不打印菜单和额外提示文字。

## 建议实现

- 定义 Node 和 CircularList（head、length），用 malloc 分配真正的指针节点。
- 实现 `initList / insert_at / delete_at / rotate / listNode / release`。
- 最后一个数据节点的 next 必须指向头节点，不能用 NULL 结束。
- 旋转通过改变 next 链接完成，不复制数据；释放时只走一圈，最后释放头节点。

## 分步提示

遍历结束条件是 p==head，而不是 p==NULL。删除最后一个数据节点后，head->next 要重新指向 head。先取 k%length，但必须先排除 length==0，避免除零。

## 样例

输入：
```text
3 7
1 2 3
3 1
4
1 4 9
2 1
3 5
4
5
```

输出：
```text
2 3 1
OK
2
9 3 1
3
```
