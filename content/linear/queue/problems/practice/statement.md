# 实现队列的三个操作

第一行 q（1～100），接着 q 行操作：`1 x` 入队，`2` 出队并输出值，`3` 查看队头并输出值。

补全 enqueue、dequeue、front_value。用 [front,rear) 表示有效段，输入保证出队和查看合法。每次查询单独输出一行；查看不得改变 front。此处不做循环队列。

## 本地样例

输入：
```text
7
1 3
1 5
3
2
1 7
2
3
```

输出：
```text
3
3
5
7
```
