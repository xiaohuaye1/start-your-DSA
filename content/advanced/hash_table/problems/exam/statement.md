# 洛谷 P3370 · 字符串哈希

来源：[洛谷 P3370](https://www.luogu.com.cn/problem/P3370)。题意转述，样例和参考实现自行编写。

给定 N 个由数字、大小写字母构成的字符串，统计不同字符串的数量，大小写敏感。N≤10000，单串最长 1500。参考框架用链式桶保存原串，补全 already_seen；同桶仍须比较完整字符串。本地仅 4～6 个短字符串。

## 本地样例

输入：
```text
5
cat
dog
cat
Dog
bird
```

输出：
```text
4
```
