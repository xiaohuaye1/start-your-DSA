# 动态规划：0/1 背包

## 状态和边界
dp[c] 表示容量不超过 c 的最大价值。每件物品最多使用一次。初始 dp 全 0；这是“不超过”容量，不是要求恰好装满。

## 转移
对重量 w、价值 v，比较不选 dp[c] 和选一次 dp[c-w]+v。优化成一维数组后，c 从大到小，保证来源还是上一个物品的状态。正序可能重复使用当前物品，变成另一种问题。

## 动画
容量固定 6，重量依次循环 1、2、3，用户输入是正整数价值。逐格对照前一行与当前 dp，显示候选来源；保存教学行用于回溯所选物品。练习支持自行输入容量与每件重量/价值。

## 实操与真题
实操第一行是 n capacity；P1048 第一行是总时间 T 与药材数 M，随后都是 weight value。药材每株只能采一次，目标最大总价值；真题 T≤1000、M≤100，重量和价值为 1～100。本地容量仅 4～6、物品 3～4 件。

## 复杂度与限制
一维参考代码时间 O(nC)、额外空间 O(C)。动画为回溯保存教学行，空间不同于一维参考程序。当前只实现 0/1 背包入门，不声称覆盖全部动态规划模型。本地每题仅 3 个短用例。
