# 综合实战：小根堆建立哈夫曼树并编码

## 训练目标

把小根堆、动态树节点和递归真正组合起来。不只算最小合并费用，还要建立哈夫曼树，恢复每个叶子的 0/1 编码，并计算 WPL。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调，不要直接抄整份参考答案。

## 输入

第一行 n，第二行 n 个正整数权值，按输入顺序给叶子编号 1～n。1≤n≤12，权值为 1～100。

为了让编码结果唯一：小根堆先按权值升序，再按节点编号升序取节点。合并产生的内部节点编号依次为 n+1、n+2……；每次先取出的节点作为左孩子（0），后取出的作为右孩子（1）。

## 操作与输出

第一行输出 WPL，即所有叶子的 `权值×根到叶子的边数` 之和。

随后 n 行按原叶子编号输出 `编号 编码`。只有一个叶子时，WPL 为 0、编码约定为 `0`。注意显示编码 0 的长度是 1，但树中叶子深度仍为 0。

不能只输出合并费用；要输出每个叶子的完整编码。

## 建议实现

- 定义 HuffNode（weight、id、left、right）和存放 HuffNode* 的 MinHeap。
- 实现 `less / heap_push / heap_pop / build / collect_codes / release`，不使用标准库优先队列代替本章小根堆练习。
- 用 malloc 建立叶子及内部节点，让孩子指针指向真实节点。
- DFS 从根恢复每个叶子的编码，用 DFS 深度算 WPL；退出前释放整棵树。
- 同权比较规则必须同时用于堆上浮与下沉。

## 分步提示

小根堆每次取两个根，并不是简单取原数组的两个最小值，因为新合并节点也要参与后续比较。编码输出顺序仍按原叶子编号，不按 DFS 顺序。可以用“合并费用总和”交叉检查 WPL。

## 样例

输入：
```text
4
1 1 2 3
```

输出：
```text
13
1 110
2 111
3 10
4 0
```

## 写完后自查

权值相同时编码是否稳定？是否把内部节点当作叶子输出了？只有一个叶子时为什么 WPL 不等于该权值？释放内部节点后是否还会访问孩子？
