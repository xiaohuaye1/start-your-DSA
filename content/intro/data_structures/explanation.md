# 数据结构简介

## 数据、结构与操作
数据结构不仅是存放数据的容器，还规定关系和操作。相同的一串数字，用数组、栈或队列组织时，访问规则不同。

- 数组：按下标访问。
- 栈：后进先出，常用 push / pop。
- 队列：先进先出，在后续课程单独实现。

## 动画中的栈
先按输入顺序入栈，再从栈顶取出。右侧 top 是最后一个有效元素的下标，空栈时为 -1。下方同步展示当前栈和输出序列，输出刚好是输入的逆序。

```c
a[++top] = value; /* push */
value = a[top--]; /* pop: check nonempty first */
```

## 为什么能逆序
最后进入的数字最先取出。数组也可以从 n-1 往 0 访问，得到同样的输出；实操使用原地双指针反转，额外空间 O(1)，动画则突出栈的访问规则。

## 易错点
不得对空栈 pop；有效元素数量是 top+1；终止标记 0 不属于数据。真题 P1427 可以用数组逆序输出，无须强行实现栈。
