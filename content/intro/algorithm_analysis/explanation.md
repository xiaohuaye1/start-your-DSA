# 算法分析

## 分析什么
先确认正确性，再估计执行次数、时间增长和额外空间。动画用两个模型比较：单层循环执行 n 次；两个都执行 n 次的嵌套循环执行 n² 次。

## 动画的含义
输入数组的长度就是 n，元素数值不影响循环次数。先演示单层循环，再把每个 (i,j) 位置涂色，表示双层循环完成一次主体执行。下方条形图展示完成比例，不是性能跑分。

```c
for (int i = 0; i < n; ++i)
    for (int j = 0; j < n; ++j)
        ++count;
```

## 不是所有双层循环都是 O(n²)
要看每层的边界和总次数。例如 j < i 的总次数为 n(n-1)/2，仍是 O(n²)；如果内层总共只前进 n 次，则不能机械相乘。

## 正确性与停止条件
P1035 要找到调和和严格大于 k 的最小 n。循环继续条件是 sum <= k；1.0/n 是浮点除法，1/n 会发生整数除法。循环次数取决于实际终止时的 n，不能直接认定为 O(k)。

## 本地范围
动画最多 8 个元素，双层循环最多 64 次；真题只测试 k=1,2,3，不在电脑上运行官方最大输入。
