# 结构体回顾与学习

## 把相关字段放到一起
一个学生的学号和成绩应一起保存。结构体定义一种记录类型，不会自动创建具体的学生。

```c
typedef struct {
    int id;
    int score;
} Student;
Student a[100];
```

## 动画中的记录
初始数组中的数值作为 score，id 自动取 1～n。逐条读取记录，用成绩比较，再把整个 Student 记录赋给 best。字段卡片展示当前记录与已保存的最优记录。

## 访问与传递
变量使用 student.score；指针使用 p->score。best = a[i] 复制全部字段，不能只复制分数而忘记学号。动画是逻辑字段示意，不模拟真实的字节布局或内存对齐。

## 同分怎么处理
实操成绩相同选学号更小的记录。真题 P1093 依次按总分降序、语文降序、学号升序比较；总分需先由三科成绩计算。

## 与排序的联系
P1093 可以使用已有冒泡排序的相邻交换框架，但交换的是整个 Student，而非单独的分数。本地只有 5～7 名学生，重点是记录组织和比较规则。
