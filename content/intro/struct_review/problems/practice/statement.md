# 结构体实战：学生记录管理器

## 训练目标

不再只找一次最高分。自己定义 Student 和 StudentList，把新增、查找、修改、删除、统计拆成独立函数；结构体通过指针传给修改函数。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调命令，不要直接抄整份参考答案。

## 输入

第一行 n q，接着 n 行 id score，随后 q 行操作。初始 id 不重复。0≤n≤8，1≤q≤16；id 为 1～100，score 为 0～100，同时存在的记录不超过 20 条。

## 操作与输出

| 操作 | 要做的事与输出 |
| --- | --- |
| `1 id score` | 修改已有记录；成功输出 `OK`，没有该 id 输出 `NOT_FOUND` |
| `2 id` | 删除并输出原分数；没有该 id 输出 `NOT_FOUND` |
| `3 id score` | 新增；成功输出 `OK`，id 已存在输出 `EXISTS`，不要覆盖旧分数 |
| `4` | 输出最高分记录的 `id score`；同分取较小 id，空表输出 `EMPTY` |
| `5` | 输出 `记录数 分数总和` |
| `6 id` | 输出该记录的分数；不存在输出 `NOT_FOUND` |

所有查询或状态输出各占一行，不打印菜单和额外提示文字。

## 建议实现

- 用 `typedef struct` 定义记录和顺序记录表，操作函数接收 `StudentList *L`。
- 实现 `initList / find / append / update / delete_at / best / statistics`，main 只负责读操作和打印结果。
- 删除后移动剩余记录、同步 length；修改之后重新计算最佳记录，而不是沿用旧缓存。

## 分步提示

先实现查找，再复用它完成修改和删除。`score == 0` 仍是有效记录，不能拿 0 代表“没找到”。操作函数返回成功/失败，数据用指针参数或下标交给 main。

## 样例

输入：
```text
3 8
1 60
2 90
3 90
4
1 1 95
4
2 1
3 4 90
4
6 1
5
```

输出：
```text
2 90
OK
1 95
95
OK
2 90
NOT_FOUND
3 270
```
