# 找出成绩最高的学生

补全 `best_student`。每个 Student 含 id 和 score；选出分数最高者，同分选学号更小者。

## 输入输出
第一行 n（1～100），接下来 n 行各为 `id score`；id 为互不重复的正整数，score 为 0～100。输出获选学生的 `id score`。

请整体复制记录，不要把学号和成绩拆散。

## 本地样例

输入：
```text
3
1 82
2 95
3 88
```

输出：
```text
2 95
```

## 本地演练

只提供 3 个小规模用例，每组最多 8 个元素或记录，不运行极端输入；每组限时 2 秒。运行样例不计完成，提交全部通过后完成本环节。
