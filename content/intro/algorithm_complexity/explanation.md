# 算法与复杂度

## 什么是算法
算法是一组明确、有限的步骤，把输入变成输出。求数组总和就是：初始化 sum、依次读取元素、累加、输出结果。

## 跟着动画走
黄色表示当前读取位置，绿色表示已处理。右侧 i、sum、reads 同步变化；下方代码行显示当前语句。改动数组长度，再观察访问次数。

## 时间与空间
长度为 n 时读取 n 次，时间复杂度 O(n)。输入数组占 O(n) 空间，但算法额外只使用 i 和 sum，所以额外空间 O(1)。复杂度描述增长趋势，不是实测秒数。

```c
long long sum = 0;
for (int i = 0; i < n; ++i) sum += a[i];
```

## 易错点
sum 要初始化；循环条件是 i < n；用 long long 避免累加溢出。本地小测试不能证明所有大数据都正确。

## 实操与真题
实操补全遍历求和。洛谷 P1001 练习输入—处理—输出的最小算法；它只做一次加法，可看作固定字长整数模型下的 O(1)，并不等同于动画的 O(n) 遍历。
