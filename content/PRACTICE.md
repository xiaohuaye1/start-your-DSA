## 建议怎么练

1. 从空白写类型定义和函数接口，明确每个函数读什么、改什么、返回什么。
2. 先实现初始化、插入或入队，用自己写的小 main 验证。
3. 再加入删除、查询、遍历等操作，最后连通题目要求的输入输出。
4. 根据自查问题检查指针连接、普通边界、内存释放和复杂度。
5. 卡住先看分步提示；参考代码是完整示例，不会自动放进编辑器。

动态节点采用 malloc/free 的 C 风格；参考实现也可以用 C++17 编译。
修改结构体使用指针参数；数据值和“成功/失败”分开返回，避免将合法的 0 当作错误。
不要把函数取名为 delete，因为它是 C++ 关键字。

## 用例与旧记录

每题仍只有 3 个小用例，包含通常会遇到的空结构、满结构、回绕、重复值、
非法位置或不可达点。没有大规模压力数据。题面里的自选加练不参与这 3 个用例的判题。

新题使用以 `.workshop_v2` 结尾的独立 ID。旧草稿和提交仍在本地数据库中保留，
不会被删除或当成新题答案；旧笔记仍能直接看到，新题需要重新完成。
旧题代码不会自动迁移进新题编辑器，因为输入和任务已改变。

本地判题只能检查输入输出，不能证明提交真的用了指针、释放了内存或达到了指定复杂度。
请配合实现要求和自查，不把 3 个用例通过当作完整代码审查。
