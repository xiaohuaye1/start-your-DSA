# 二叉树实战：建树、四种遍历与层序深度

## 训练目标

不用预先给定 children 数组，自己从含 # 的前序字符串动态建树。再分别完成递归遍历、层序遍历、用队列计算深度、数叶子和释放树。

编辑器仍然从空白开始，请自己写完整程序。建议先完成基础操作，再联调，不要直接抄整份参考答案。

## 输入

一行合法前序字符串，由 A～Z 和 # 组成，# 表示空子树。最多 12 个数据节点，字符串长度最多 25，保证能完整解析为一棵树。# 单独出现时表示空树。

## 操作与输出

按顺序输出 5 行：

1. 前序遍历字符串。
2. 中序遍历字符串。
3. 后序遍历字符串。
4. 层序遍历字符串，从左到右逐层输出。
5. `深度 叶子数 节点总数`。

前四行不在字母间加空格；空树时这四行都输出 `EMPTY`。空树深度为 0，根节点是第 1 层。

不打印菜单和额外提示文字。

## 建议实现

- 定义 TreeNode（data、lchild、rchild），用 `createTree(TreeNode **T, ...)` 建树，并理解什么时候需要二级指针。
- 实现 `preorder / inorder / postorder / levelorder / depth / leafCount / nodeCount / release`。
- 层序遍历和深度计算复用一个元素类型为 `TreeNode *` 的 Queue；深度按每层节点数推进。
- 退出前递归释放整棵树，不将字母编号直接当成树节点存储。

## 分步提示

每读一个字符都推进一次游标；读到 # 立即把当前子树置 NULL。计算深度时，先记录当前队列 size，再只处理这一层；不要把新入队的孩子也算在同一层。

## 样例

输入：
```text
ABD##E##C#F##
```

输出：
```text
ABDECF
DBEACF
DEBFCA
ABCDEF
3 3 6
```
