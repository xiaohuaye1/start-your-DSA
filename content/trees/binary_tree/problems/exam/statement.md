# 洛谷 P1305 · 新二叉树

来源：[洛谷 P1305「新二叉树」](https://www.luogu.com.cn/problem/P1305)。以下为本项目题意转述，样例与参考代码自行编写。

输入 n，随后 n 行各三个字母/符号，分别代表节点、左孩子、右孩子。* 表示空孩子，第一行给出的节点必为根。输出不加空格的前序遍历字母串。原题 n≤26；本地只有 4～6 个节点。

## 本地样例

输入：
```text
5
abc
bde
c**
d**
e**
```

输出：
```text
abdec
```
