# 二分查找

## 前提与目标
数组必须非降序。存在重复值时，本课找第一个等于 target 的位置，不是任意命中点。动画会明确展示排序后的输入，再搜索其中间值；输入原顺序不用于原下标查询。

## 半开区间
维护 [left,right)，right 最初为 n。若 a[mid]>=target，则 right=mid；否则 left=mid+1。区间为空时 left 是第一个不小于 target 的候选位置，还须检查是否真的相等。

## 编号
动画内部用 0 基下标；题目输出 1 基位置，不存在时为 -1。单次查询 O(log n)，额外空间 O(1)。不能先排序实操输入来假装它符合前提，否则会改变原编号；题目已保证有序。
