# 插入排序

## 有序前缀
把 a[i] 暂存为 key，左边 a[0..i-1] 已有序。将大于 key 的元素依次右移，把 key 放入空位；每轮扩大有序前缀。

## 动画中的空位
key 卡片保存拿出的值，“·”标记当前空位。右移时数组槽位可能暂时保留旧值，但空位不属于当前有效数据；把有效槽位加上 key，仍恰好是原来的全部元素。回退会同时恢复 key、空位和数组。

## 比较顺序
先检查 j>=0，再访问 a[j]，避免负下标。用 a[j]>key 而不是 >=，相等的旧记录不右移，因此该版本稳定。

## 复杂度
已排序输入只需线性比较，最好 O(n)；一般和最坏 O(n²)，额外空间 O(1)。不应把动画速度当作复杂度证明。

## 真题
P1152 先计算相邻差的绝对值，再把差值排序，检查它们是否正好为 1～n-1。只检查最大最小值或总和都可能漏掉重复差值。输出大小写必须为 Jolly / Not jolly；本地只用 4～5 个小整数。
