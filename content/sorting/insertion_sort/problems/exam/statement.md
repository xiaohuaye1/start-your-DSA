# 洛谷 P1152 · 欢乐的跳

来源：[洛谷 P1152「欢乐的跳」](https://www.luogu.com.cn/problem/P1152)。题意转述，样例及参考代码自行编写。

输入 n 和 n 个整数。若 n-1 个相邻差的绝对值恰好包含 1～n-1 各一次，输出 Jolly，否则输出 Not jolly。

原题 1≤n≤1000，数值在 -10^8～10^8 之间。参考实现也可读取直到 EOF 的多组输入；本地每例只含一组 4～5 个小整数。补全 insertion_sort，对差值数组排序后核对。

## 本地样例

输入：
```text
4
1 4 2 3
```

输出：
```text
Jolly
```
