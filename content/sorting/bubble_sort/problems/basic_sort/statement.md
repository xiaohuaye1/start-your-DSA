# 实操训练：完成冒泡排序

补全 `bubble_sort` 函数，将输入数组按升序排列。模板已提供输入输出。

## 输入

第一行一个整数 n（1 ≤ n ≤ 1000）。第二行 n 个整数，每个整数范围为 -100000 到 100000。

## 输出

输出排序后的 n 个整数，用空格分隔。

## 样例

输入：
```text
8
5 2 8 1 6 3 7 4
```

输出：
```text
1 2 3 4 5 6 7 8
```
