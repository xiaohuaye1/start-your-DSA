# 冒泡排序：让较大的元素逐步向右移动

一轮从左到右检查相邻元素。如果左边比右边大，就交换它们。完成一轮后，当前最大值位于最右侧，下轮可以少检查一个位置。

例如 `5 2 8 1`：先交换 5 和 2，得到 `2 5 8 1`；5 和 8 顺序正确；再交换 8 和 1，得到 `2 5 1 8`。8 已归位。

播放区只展示算法过程，下面同步展示变量和数组状态。你可以输入自己的数组，也可以用上一步、下一步和进度条逐步观察。

## 对应的 C 思路

```c
for (int i = 0; i < n - 1; ++i) {
    int swapped = 0;
    for (int j = 0; j < n - i - 1; ++j) {
        if (a[j] > a[j + 1]) {
            int t = a[j];
            a[j] = a[j + 1];
            a[j + 1] = t;
            swapped = 1;
        }
    }
    if (!swapped) break;
}
```
