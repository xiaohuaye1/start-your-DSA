# 洛谷 P5715 · 三位数排序

来源：[洛谷 P5715「三位数排序」](https://www.luogu.com.cn/problem/P5715)。题意转述，样例及参考代码自行编写。

输入恰好三个整数 a,b,c，输出从小到大排列的三个数，重复值不能删除。

原题 0≤a,b,c≤100。使用选择排序完成三个位置的比较与交换；每个本地用例也只有 3 个数。

## 本地样例

输入：
```text
3 1 2
```

输出：
```text
1 2 3
```
