# 洛谷 P1177 · 排序

来源：[洛谷 P1177「排序」](https://www.luogu.com.cn/problem/P1177)。以下为本项目题意转述，样例与参考代码自行编写。

输入 N 和 N 个正整数，升序输出。原题 N≤100000，值在 1～10^9；本课使用堆排序。本地每组仅 4～6 个小整数。

## 本地样例

输入：
```text
4
3 1 4 2
```

输出：
```text
1 2 3 4
```
