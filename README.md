# Start Your DSA

一个用来学习数据结构与算法的桌面软件。

先看动画理解思路，再用 C/C++ 自己写代码，最后通过练习检查掌握情况。

## 可以做什么

- 看动画：支持播放、暂停、上一步、下一步和调速。
- 写代码：支持 C/C++，可以运行样例、输入自己的测试数据、提交判题。
- 做真题：每节配有洛谷题目，可打开原题继续练习。
- 记笔记：自动保存笔记、代码草稿和学习进度。
- 查课程：左侧可以搜索课程，也可以拖动分隔条调整宽度。

目前共有 28 节课，每节包含三个环节：**动画演示、实操训练、真题演练**。

## 下载与启动

1. 在本仓库的 **Releases** 页面，下载 Windows 64 位的 `Start-Your-DSA-0.2.0-win-x64.zip`。
2. 将 ZIP **全部解压**，然后双击解压目录里的 `Start Your DSA.exe`。
3. 在左侧选择一节课，再点击它下面的学习环节。
4. 看完动画后进入实操，自己编写完整的 C/C++ 程序。
5. 点击“运行样例”检查输出，再点击“提交判题”检查答案。

不需要下载源码，也不需要安装 Python、Node.js 或配置 GCC/G++，软件已经内置运行环境和编译器。
本地发布包放在 `release/Start-Your-DSA-0.2.0-win-x64.zip`。

只需要解压一次，以后直接打开 EXE，不会每次启动都重新解压。
不要在压缩包里直接运行，也不要只拿出 EXE；旁边的文件和文件夹都需要保留。
关闭软件后，笔记、草稿和进度不会丢失。

编辑器默认空白，不会自动填入答案。你保存过的个人草稿会恢复，需要时可以单独查看“参考代码”。

## 学些什么

- 入门：算法与复杂度、数据结构简介、算法分析、结构体。
- 线性结构：数组、链表、循环链表、双向链表、栈、队列、循环队列。
- 查找与排序：排序概述、冒泡、选择、插入、快速、归并、堆排序、二分查找。
- 树与图：二叉树、平衡二叉树、堆、图的基础、图的遍历。
- 进阶练习：哈希表、贪心算法、动态规划、数据结构综合训练。

## 使用时注意

- 动画是预先设计的教学演示，不会把你写的代码自动变成动画。
- 每道题只在本地检查 3 个小测试用例，不运行大规模或极端输入。
- 本地通过不代表通过洛谷官方评测，想完整检验可以到洛谷提交。
- 代码在你自己的电脑上运行，请只运行自己写的或可信的代码。
- 这是学习用的桌面项目，目前没有账号同步或在线判题。便携版不需要安装。

## 发布到 GitHub

1. 把项目源码上传到仓库，`release/`、`node_modules/` 等目录不用提交。
2. 在仓库页面打开 **Releases → Draft a new release**。
3. 将 `release/Start-Your-DSA-0.2.0-win-x64.zip` 拖到附件区，供用户下载。

ZIP 是打包后的软件，放在 Releases 附件中，不要直接提交到源码仓库。
公开发布前还需要检查第三方许可证和对应源码的提供要求，见 `packaging/THIRD-PARTY.md`。

## 源码说明

仓库保留源码，供查看、修改和重新打包。普通用户下载 Releases 中的 ZIP，解压后运行 EXE 即可。

界面使用 JavaScript + Electron，课程读取和本地判题使用 Python，C/C++ 编译使用 GCC/G++。

主要文件位置：

```text
desktop/   软件界面和动画
app/       课程读取、编译判题、数据保存
content/   课程讲解、题目和参考代码
tests/     功能测试
packaging/ Windows EXE 打包工具（开发者使用）
```

修改外观主要看 `desktop/styles.css`，修改界面交互主要看 `desktop/renderer.js`。
重新打包的方法见 `packaging/README.md`。

个人笔记和进度不在项目文件夹里。需要备份时，可以在软件“帮助”中查看数据目录，复制其中的 `learning.db` 和 `settings.json`。
