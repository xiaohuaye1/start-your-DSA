# Start Your DSA

一个用来学习数据结构与算法的桌面软件。

先看动画理解思路，再用 C/C++ 自己写代码，最后通过练习检查掌握情况。

## 可以做什么

- 看动画：支持播放、暂停、上一步、下一步和调速。
- 写代码：支持 C/C++，可以运行样例、输入自己的测试数据、提交判题。
- 做真题：每节配有洛谷题目，可打开原题继续练习。
- 记笔记：自动保存笔记、代码草稿和学习进度。
- 查课程：左侧可以搜索课程，也可以拖动分隔条调整宽度。

目前共有 28 节课，每节包含三个环节：**动画演示、实操训练、真题演练**。

## 怎么开始

1. 打开项目文件夹，双击 `启动.bat`。
2. 在左侧选择一节课，再点击它下面的学习环节。
3. 看完动画后进入实操，自己编写完整的 C/C++ 程序。
4. 点击“运行样例”检查输出，再点击“提交判题”检查答案。

编辑器默认空白，不会自动填入答案。你保存过的个人草稿会恢复，需要时可以单独查看“参考代码”。

第一次在新电脑上使用，需要准备：

- Node.js 22.12 或更高版本。
- Python 3.11 或更高版本。
- GCC/G++ 编译器（写代码练习时使用）。

装好 Node.js 和 Python 后，双击 `安装依赖.bat`，完成后再启动。桌面上已有的版本如果能正常打开，就不用重新安装依赖。

如果提示找不到编译器，在顶部“设置”中选择 `gcc.exe` 和 `g++.exe`。只看动画和阅读讲解不需要编译器。

## 学些什么

- 入门：算法与复杂度、数据结构简介、算法分析、结构体。
- 线性结构：数组、链表、循环链表、双向链表、栈、队列、循环队列。
- 查找与排序：排序概述、冒泡、选择、插入、快速、归并、堆排序、二分查找。
- 树与图：二叉树、平衡二叉树、堆、图的基础、图的遍历。
- 进阶练习：哈希表、贪心算法、动态规划、数据结构综合训练。

## 使用时注意

- 动画是预先设计的教学演示，不会把你写的代码自动变成动画。
- 每道题只在本地检查 3 个小测试用例，不运行大规模或极端输入。
- 本地通过不代表通过洛谷官方评测，想完整检验可以到洛谷提交。
- 代码在你自己的电脑上运行，请只运行自己写的或可信的代码。
- 这是学习用的桌面项目，目前没有账号同步、在线判题或独立安装包。

## 想修改项目？

界面使用 JavaScript + Electron，课程读取和本地判题使用 Python，C/C++ 编译使用 GCC/G++。

主要文件位置：

```text
desktop/   软件界面和动画
app/       课程读取、编译判题、数据保存
content/   课程讲解、题目和参考代码
tests/     功能测试
scripts/   启动和安装脚本
```

修改外观主要看 `desktop/styles.css`，修改界面交互主要看 `desktop/renderer.js`。

个人笔记和进度不在项目文件夹里。需要备份时，可以在软件“帮助”中查看数据目录，复制其中的 `learning.db` 和 `settings.json`。
